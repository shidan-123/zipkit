ZipKit 免安装版 · 使用说明
================================

这个文件夹里有两个程序：

  ZipKit.exe     ← 双击打开图形界面（推荐）
  zipkit.exe     ← 命令行版，给批处理、脚本用

不需要安装 Python，也不需要联网。所有文件都在你自己的电脑上处理。


第一次打开
----------
Windows 可能提示「Windows 已保护你的电脑」：

    点【更多信息】→ 点【仍要运行】

这是应用没有购买代码签名证书时的正常提示，不是病毒。
程序不含任何联网代码，可以断网使用。


如果杀毒软件误报
----------------
把本文件夹加入信任名单即可。
报错通常是因为 exe 未签名 + 内部打包了 Python 运行时，属于启发式误判。


图形界面怎么用
--------------
  压缩：点「添加文件」或「添加文件夹」→ 选级别 → 开始压缩
  解压：点「浏览」选压缩包 → 开始解压

大文件（几百 MB）也能处理，进度条会显示百分比和已处理字节数。


命令行怎么用
------------
  zipkit.exe --help
  zipkit.exe pack 报告.txt 数据.csv -o 打包.zip
  zipkit.exe unpack 打包.zip -d 输出目录
  zipkit.exe list 某个包.zip
  zipkit.exe check 某个文件.wav
  zipkit.exe text 报告.docx


遇到问题
--------
日志位置：%LOCALAPPDATA%\ZipKit\crash.log
项目地址：https://github.com/shidan-123/zipkit
