## 二、一键发布（推荐）

```bash
cd zipkit

# 1. 本地自检 + 重建 App + 打 zip（产物在 dist/）
make release

# 2. 提交这次发布准备的改动
git add -A
git commit -m "chore(release): 统一版本号、加 CI 与打包脚本，准备 v1.1.3"

# 3. 推代码
git push origin main

# 4. 打 tag —— 推上去后 release.yml 会自动建 Release 并挂上 zip
git tag -a v1.1.3 -m "ZipKit v1.1.3：窗口版大文件无限制 + 应用包自包含"
git push origin v1.1.3
```

推完 tag 后到 **Actions → release** 看进度；绿了就去
<https://github.com/shidan-123/zipkit/releases> 检查产物。

> 如果 Actions 没有自动触发，多半是仓库没启用 Actions：
> Settings → Actions → General → "Allow all actions"。

## 三、手动发布（不想用 Actions 时）

1. 本机跑 `make release`，得到：
   - `dist/ZipKit-1.1.3-macos.zip`
   - `dist/SHA256SUMS.txt`
2. 打开 <https://github.com/shidan-123/zipkit/releases/new>
3. Tag 选 `v1.1.3`（新建），标题 `v1.1.3 — 窗口版大文件无限制`
4. 把两个产物拖进附件区
5. 正文用下面的模板

```markdown
## 这个版本解决什么

- **大文件不再卡 64 MB**：新增独立窗口版，上限只取决于磁盘空间
  （实测 351.6 MB 的包 0.5 秒解完，SHA-256 一致）。
- **双击即开**：`ZipKit.app` 自带代码，不依赖项目文件夹位置，
  绕开 macOS 隐私保护导致的 `PermissionError`。
- **中文名不再乱码**：修复 Windows GBK 压缩包解压后的文件名。

## 下载

| 文件 | 说明 |
|---|---|
| `ZipKit-1.1.3-macos.zip` | macOS 应用包。**需要本机 Python 3.9+ 且 Tk ≥ 8.6**（推荐 python.org 的 3.13） |
| `SHA256SUMS.txt` | 校验用 |

## 安装

1. 解压 zip，把 `ZipKit.app` 拖进「应用程序」
2. 首次打开如果提示"无法验证开发者"：**右键 → 打开**（本应用未做 Apple 签名）
3. 打不开时看日志：`~/Library/Logs/ZipKit.log`

## 其他平台

Windows / Linux 用命令行，不需要这个包：

```bash
git clone https://github.com/shidan-123/zipkit.git
cd zipkit && python3 -m zipkit web
```

**完整更新：** [CHANGELOG](https://github.com/shidan-123/zipkit/blob/main/CHANGELOG.md)
```

## 七、这次**没有**做的事（说清楚，免得误会）

1. **App 没有代码签名 / 公证**：需要 Apple 开发者账号（$99/年）。
   现状是"右键打开"可用，但会被 Gatekeeper 警告一次。
2. **还不是免 Python 的单文件版**：`ZipKit.app` 本质是启动器 + 内置源码，
   依赖本机 Python。PyInstaller 打包在路线图 v1.2。
3. **Linux / Windows 没有图形安装包**：这两个平台走网页版或命令行，
   README 已写明，不是遗漏。
